2nd-Brain

プライバシーポリシー

最終更新日：2026年10月13日

1. このツールについて

2nd-Brain は、開発者本人が個人で使うためのツールです。開発者本人以外の利用は想定しておらず、一般には提供していません。

2. アクセスする Google ユーザーデータ

  • Google ドライブ：保存先フォルダとファイルの作成・読み取り・更新・移動
  • Google ドキュメント：議事録の作成と書き込み
  • Google カレンダー：予定の読み取り・登録

3. 利用目的

取得したデータは、開発者本人の議事録作成、記録のバックアップと復元、予定の管理のためだけに使います。広告、分析、機械学習モデルの学習には使いません。

4. 保存と共有

  • 認証情報（アクセストークン）は、開発者本人のパソコン内にのみ保存します。
  • Google ユーザーデータを第三者に販売・提供・共有することはありません。
  • 開発者が運営する外部サーバーへデータを送信することはありません。

5. Google API サービスのユーザーデータに関するポリシー

2nd-Brain による Google API から受け取った情報の利用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも 2nd-Brain のアクセス権を取り消せます。取り消すと、保存されている認証情報は使えなくなります。

7. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
